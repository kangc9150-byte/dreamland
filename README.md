# 🌈 梦乡 - 宠物纪念独立站

欢迎来到梦乡！这是一个专为宠物纪念打造的3D互动网站。

## 🎨 特色功能

- **立体彩虹桥** - 真实的3D拱桥，彩虹渐变效果
- **奔跑的狐狸** - 沿着彩虹桥奔向梦幻城堡
- **梦幻城堡** - 精美的多塔建筑群
- **繁花似锦的花园** - 彩色鲜花和绿树
- **金色粒子系统** - 梦幻的光点飘舞
- **实时3D渲染** - 使用 Three.js 引擎

## 🚀 访问网站

访问地址：[https://kangc9150-byte.github.io/dreamland/](https://kangc9150-byte.github.io/dreamland/)

## 🎮 交互方式

- **鼠标滚轮** - 放大/缩小视图
- **自动相机环绕** - 围绕宠物旋转
- **实时动画** - 宠物在桥上奔跑

## 📝 说明

这个项目使用了：
- Three.js（3D 图形库）
- WebGL（GPU 加速）
- GLTF 模型格式
